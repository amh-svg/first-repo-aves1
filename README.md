A Revit plugin that does [description].

## Supported Versions
- Revit 2022, 2023, 2024

## Installation

1. Download the latest release from the [Releases page](link-to-releases)
2. Copy `YourPlugin.dll` and `YourPlugin.addin` to:
   `C:\ProgramData\Autodesk\Revit\Addins\2024\`
   (Replace `2024` with your Revit version)
3. Restart Revit
4. The plugin will appear under the **Add-Ins** tab

## Updating
To update, download the new release and replace the old files in the same folder.
